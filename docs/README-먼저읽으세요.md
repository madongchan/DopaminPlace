# 도파민플레이션 — 인수인계

팀 워크숍(10~12명)용 파티게임 플랫폼입니다.
노트북에서 서버를 켜고, TV가 큰 화면이 되고, 참가자는 **휴대폰 브라우저**로 들어옵니다. 앱 설치는 없습니다.

행사일: **2026-10-15 ~ 17 중 하루**

## 2. 바로 돌려보기

Node.js 20 이상이 필요합니다 (개발은 24.18.0에서 했습니다).

```bash
cd 프로젝트
npm install          # node_modules 는 용량 때문에 뺐습니다
node server/index.js # 또는 서버켜기.bat 더블클릭 (Windows)
```

| 주소 | 누가 봅니까 |
| --- | --- |
| `http://localhost:3000/screen` | TV 큰 화면 (F11 전체화면) |
| `http://localhost:3000/` | 참가자 휴대폰 |
| `http://localhost:3000/admin` | 진행자 (기본 PIN `0000`) |

혼자 테스트하려면 가짜 참가자를 넣으세요.

```bash
node tools/bots.js 11
```

## 5. 구조 — 새 게임 하나 붙이는 법

게임은 **모듈 하나**입니다. 다른 게임 코드를 건드릴 일이 없습니다 (SPEC 3장). 실제로 6종을 붙이는 동안 한 번도 안 건드렸습니다.

```
server/games/<이름>/index.js     ← 규칙·점수 (서버가 모든 상태를 가짐)
public/games/<이름>/screen.js    ← TV
public/games/<이름>/player.js    ← 휴대폰
public/games/<이름>/admin.js     ← 진행자
server/games/index.js            ← import 한 줄 + 목록 한 칸 추가
tools/bots.js 의 게임별행동       ← 봇 행동 한 칸
```

서버 모듈이 내보내야 하는 것:

```js
{ id, name, type: 'team'|'solo'|'offline', minPlayers, maxPlayers, minutes,
  rules, color,
  create(ctx), onInput(s, playerId, input), onAdmin(s, action),
  onTick(s, now), views(s), result(s) }
```

화면 쪽 호출 규약:

```js
// screen.js
export function 그리기(el, current, 화면뷰) {}
// player.js  — 보내기(payload) 로 입력 전송
export function 그리기(el, current, 보내기) {}
// admin.js   — 조작(action, payload) 로 진행자 조작
export function 그리기(el, current, 조작, 진행자뷰) {}
```

## 6. 반드시 지켜야 할 것

### ① 정보 등급 (SPEC 4장) — 가장 중요

`views(s)` 는 네 가지를 돌려줍니다.

```js
{ screen, player: (pid) => …, admin, adminSecret }
```

**비밀은 화면에서 가리는 게 아니라 보내는 데이터에서 빼야 합니다.** 개발자도구로 다 보입니다.

- 마피아 역할, 라이어 정체, 남의 답 → 그 사람 뷰에 **넣지 않습니다**
- **진행자에게도 안 보냅니다.** 진행자(기획자 본인)도 참가자로 참여하기 때문입니다
- 꼭 봐야 하면 `adminSecret` + '스포일러 보기'로만

### ② 끝까지 숨겨야 하는 것은 `data/secret.json` 에만

`server/secret.js` 를 쓰세요. 역할뿐 아니라 **"누가 그 역할인지 드러나는 기록"**도 같이 옮겨야 합니다.

> 실제로 마피아에서 `경찰기록`·`군인방패`·`점수메모`를 참가자 id로 묶어 게임 상태에 뒀더니
> `data/state.json` 파일만 열면 누가 경찰·군인인지 드러났습니다. 테스트가 잡아냈습니다.
> 변수 이름도 조심하세요 (`의사직전` → `지난보호` 로 바꿨습니다).

### ③ 그 밖에

- **서버가 모든 상태를 가집니다.** 화면은 서버가 준 것만 그립니다.
- **타이머**는 서버가 `endsAt`(밀리초)만 주고, 화면이 각자 셉니다.
- **외부 CDN 금지** (SPEC 11장). socket.io 클라이언트와 anime.js도 `node_modules`에서 우리 서버가 내보냅니다 (`/vendor/…`).
- **빌드 과정 없음.** 프론트는 순수 HTML/CSS/ES 모듈입니다.
- **모든 글·주석·로그는 한국어.** 식별자도 한국어를 씁니다 (기존 코드와 맞추세요).
- 파일을 고치기 전 백업: `<파일명>.bak-<내용>-<YYYYMMDD>`

## 8. 아직 안 된 것 / 알아둘 것

- **구글시트 미연결.** 시트 없이도 전부 돌아갑니다(설계가 그렇습니다). 연결하면 ① 노트북이 꺼져도 휴대폰으로 점수 확인 ② 문제를 시트에서 수정 가능. 절차는 `README.md`에 있습니다. **요금은 들지 않습니다**(카드 미등록, 분당 30회 자체 제한).
- **글꼴 미적용.** 양진체(YANGJIN)를 `public/fonts/`에 넣기로 되어 있습니다 (8단계).
- **진행자 '스포일러 보기' 버튼 없음.** 서버에는 `스포일러보기` 이벤트와 `adminSecret` 뷰가 있는데 `public/js/admin.js`가 아직 호출하지 않습니다 (8단계).
- **인트로 배경 이미지**는 기획자의 기존 워크숍 PPT에서 추출한 것입니다. 외부 배포 시 라이선스 확인이 필요할 수 있습니다.
- **마피아 인원 8~12명.** SPEC 표는 10·11·12명뿐이지만, 당일 결원이 생겨도 막히지 않게 8·9명도 같은 짜임으로 넣었습니다 (기획자 결정, 2026-10-05). **10~12명 배정은 명세 그대로입니다.**
- **Windows 특이사항**: PowerShell ExecutionPolicy가 `npm.ps1`을 막습니다. `서버켜기.bat` 또는 `npm.cmd` 또는 `node server\index.js`를 쓰세요.
- **와이파이가 바뀌어도 서버는 재시작하지 않습니다.** `0.0.0.0` 바인딩 + 3초 간격 IP 감시로 QR·주소가 자동 갱신됩니다.
