# 도파민플레이션

팀 워크숍(10~12명)용 파티게임 플랫폼.
노트북에서 서버를 켜고 TV가 큰 화면, 참가자는 휴대폰 브라우저로 들어온다.

전체 명세는 `SPEC.md`, 처음 준비는 `00_시작가이드.md`를 본다.
**지금 어디까지 했고 다음에 무엇을 하는지는 `작업일지.md`에 있다.**

## 켜는 법

**가장 쉬운 방법 — `서버켜기.bat` 더블클릭.** 검은 창이 뜨면 성공이다.

PowerShell에서 직접 켜려면:

```powershell
cd C:\dev\dopamineflation
node server\index.js
```

> `npm start`가 **"이 시스템에서 스크립트를 실행할 수 없으므로"** 오류로 막힐 수 있다.
> 윈도우가 PowerShell 스크립트(`npm.ps1`)를 막아서 그렇다. 위의 `node server\index.js`는 그 제한을 받지 않는다.
> 매번 `npm`을 쓰고 싶으면 PowerShell에 아래를 한 번만 실행한다(관리자 권한 필요 없음).
>
> ```powershell
> Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
> ```

콘솔에 뜨는 내용
- **입장코드** 4자리 — 참가자가 휴대폰에 넣는 숫자
- **휴대폰 주소** `http://192.168.x.x:3000` — 참가자가 들어가는 주소
- **큰 화면 주소** `http://localhost:3000/screen` — TV에 띄울 주소

## 화면 3개

| 화면 | 주소 | 어디서 |
| --- | --- | --- |
| 큰 화면 | `http://localhost:3000/screen` | TV |
| 진행자 | `http://localhost:3000/admin` | 노트북 본 화면 (PIN 기본 `0000`) |
| 참가자 | `http://192.168.x.x:3000` | 휴대폰 |

## TV에 띄우기

1. HDMI 연결 → `Win + P` → **확장**
2. TV 쪽 브라우저 창에 `http://localhost:3000/screen` 입력
3. `F11`로 전체화면
4. 타이틀 인트로가 **계속 반복**된다. 사람들이 모일 때까지 그대로 틀어두면 된다.
5. 시작할 때 **「게임 시작하기」**를 누르면 입장 QR과 대기실이 나온다.
   - `Space` 또는 `Enter` — 버튼과 같음(바로 시작)
   - `R` — 인트로를 처음부터 다시

## 휴대폰에서 들어가기

1. 노트북과 **같은 와이파이**에 연결
2. 카메라로 TV의 QR을 찍거나, 주소를 직접 입력
3. 입장코드 → 이름(최대 6자) → 비밀번호 4자리

들어오면 TV 대기실에 이름이 뜬다.

## 안 될 때

| 증상 | 확인 |
| --- | --- |
| 휴대폰에서 주소가 안 열림 | **Windows 방화벽**. 첫 실행 때 뜬 창에서 개인·공용 네트워크 모두 '허용'했는지 확인 |
| 주소는 열리는데 입장이 안 됨 | 입장코드가 TV에 뜬 것과 같은지 확인 |
| `3000번 포트를 이미…` 메시지 | 이전 서버 창이 남아 있다. 그 창에서 `Ctrl+C` |
| 와이파이가 기기 간 통신을 막음 | `npm run tunnel` (8단계에서 구현) |
| `npm`이 "스크립트를 실행할 수 없으므로" | `서버켜기.bat`을 쓰거나 `node server\index.js` |


## 구글시트 연결 (선택)

### 돈이 드나요? — 안 듭니다

Google Sheets API는 **무료**입니다. 신용카드를 등록하지 않아도 쓸 수 있습니다.

| | |
| --- | --- |
| 구글이 허용하는 양 | 분당 300회 (하루 총량 제한 없음) |
| 우리가 3시간 행사에서 쓰는 양 | **약 51회** (전체의 0.09%) |
| 한도를 넘으면 | `429` 오류가 날 뿐, 요금이 청구되지 않음 |

2026년 후반부터 **"한도를 넘긴 경우에 한해"** Google Cloud 결제 계정으로 과금될 예정이라고
구글이 예고했습니다. 다만 두 가지 이유로 안전합니다.

1. **결제 계정을 안 붙이면 청구 자체가 불가능합니다.** 신용카드를 등록하지 않으면
   한도를 넘겨도 그냥 오류가 날 뿐입니다.
2. **우리는 한도 근처도 안 갑니다.** 서버가 5초마다 모아서 한 번에 보내고,
   문제는 게임 시작할 때만 읽습니다. 게다가 코드에 **분당 30회 자체 제한**을 걸어두어
   실수로도 넘지 않습니다. 진행자 화면에 지금까지 보낸 요청 수가 표시됩니다.

**안 해도 됩니다.** 시트를 연결하지 않아도 점수·참가자는 `data/state.json`에 그대로 저장되고
모든 기능이 똑같이 돌아갑니다. 시트를 연결하면 좋은 점은 두 가지입니다.

- 노트북이 꺼져 있어도 **휴대폰에서 시트만 열면 점수를 볼 수 있다**
- **문제를 시트에서 고칠 수 있다** (게임 시작할 때마다 다시 읽으므로 다음 판부터 바로 반영)

### 한 번만 하는 준비 (20분) — 카드 등록 없이

> **어디서도 신용카드를 묻지 않습니다.** 혹시 "결제 계정을 설정하세요" 같은 화면이 나오면
> 그냥 닫거나 건너뛰세요. Sheets API는 결제 계정 없이 동작합니다.
> 결제 수단을 등록하지 않으면 어떤 경우에도 요금이 청구될 수 없습니다.

준비물은 **개인 구글 계정 하나**뿐입니다.

#### 1단계 — 구글 클라우드에서 Sheets API 켜기

1. https://console.cloud.google.com 접속 (구글 계정으로 로그인)
2. 맨 위 프로젝트 선택 → **새 프로젝트** → 이름 `도파민플레이션` → 만들기
   - *여기서 카드를 묻지 않습니다.*
3. 왼쪽 위 검색창에 `Google Sheets API` 입력 → 클릭 → **사용** 버튼
   - *여기서도 카드를 묻지 않습니다.*

#### 2단계 — 열쇠(서비스 계정) 만들기

4. 왼쪽 메뉴 **API 및 서비스 → 사용자 인증 정보**
5. 위쪽 **+ 사용자 인증 정보 만들기 → 서비스 계정**
6. 이름은 아무거나(`dopa`) → **만들고 계속하기**
   → 역할은 **비워두고** 계속 → **완료**
7. 목록에 생긴 서비스 계정을 클릭 → 위쪽 **키** 탭
8. **키 추가 → 새 키 만들기 → JSON → 만들기**
   → 파일이 자동으로 다운로드됩니다

#### 3단계 — 열쇠를 프로젝트에 넣기

9. 받은 파일 이름을 **`service-account.json`** 으로 바꾸기
10. `C:\dev\dopamineflation\secrets\` 폴더에 넣기
    (그 폴더에 있는 `여기에 키파일을 넣으세요.txt` 참고)

#### 4단계 — 시트 만들고 공유하기

11. https://sheets.new 로 새 시트 만들기 (이름은 `도파민플레이션`)
12. 오른쪽 위 **공유** 클릭
13. 아래 명령을 실행하면 **붙여넣을 주소가 화면에 나옵니다.**

    ```powershell
    cd C:\dev\dopamineflation
    node tools\시트확인.mjs
    ```

    `서비스 계정 주소: dopa@....iam.gserviceaccount.com` 이라고 나온 것을
    공유창에 붙여넣고 권한을 **편집자**로 바꾼 뒤 **보내기**
    (「알림 보내기」 체크는 꺼도 됩니다)

#### 5단계 — 시트 주소 알려주기

14. 시트 주소창을 보면 이렇게 생겼습니다.

    ```
    https://docs.google.com/spreadsheets/d/1AbCdEf...XyZ/edit
                                           └──── 이 부분 ────┘
    ```

15. `C:\dev\dopamineflation\.env` 를 메모장으로 열고
    `SHEET_ID=` 뒤에 그 부분을 붙여넣고 저장

#### 6단계 — 확인하고 탭 만들기

```powershell
node tools\시트확인.mjs      # 다 됐는지 확인 (아무것도 안 바꿈)
node tools\sheet-init.js     # 탭 9개와 문제 만들기
```

`시트확인`이 **[O] 연결 성공** 이라고 하면 끝입니다.
서버를 다시 켜면 `구글시트 연결됨` 이라고 뜹니다.

### 잘 안 될 때

**먼저 이것부터 실행하세요.** 무엇이 빠졌는지 한 줄씩 알려줍니다.

```powershell
node tools\시트확인.mjs
```

| 나오는 말 | 할 일 |
| --- | --- |
| `SHEET_ID 가 비어 있습니다` | `.env` 를 열어 `SHEET_ID=` 뒤에 붙여넣기 |
| `SHEET_ID 에 주소 전체가 들어갔습니다` | 화면이 알려주는 짧은 글자만 남기기 |
| `service-account.json 이 없습니다` | 파일 이름과 위치 확인 (`secrets` 폴더) |
| `편집자로 공유했는지 확인하세요` | 화면에 나온 주소를 시트 [공유]에 넣기 |

### 행사 중에

진행자 화면 점수판 아래에 상태가 보입니다.

- **시트 최신** — 다 보냈음
- **시트 보내는 중 · 대기 n줄** — 보내는 중(5초마다 자동)
- **시트 오류 · 대기 n줄** — 인터넷이 끊겼거나 권한 문제. **점수는 안 사라집니다.**
  나중에 연결되면 그대로 올라갑니다. 급하면 「지금 동기화」를 누르세요.
- **시트 안 씀 (로컬 저장만)** — 시트를 연결하지 않은 상태

## 와이파이가 바뀌면

**서버는 끄지 않아도 된다.** 노트북 IP가 달라지면 서버가 3초 안에 알아채고
TV의 QR과 주소를 저절로 새로 그린다. 큰 화면에 "접속 주소가 바뀌었습니다" 알림이 뜨면
참가자에게 QR을 다시 찍으라고 안내하면 된다. **이미 들어와 있는 사람은 그대로 있어도 된다.**

## 끄는 법

서버 창에서 `Ctrl + C`.
참가자·점수는 `data/state.json`에 저장되므로 다시 켜도 이어진다.

## 점검

```powershell
node tools\smoke-1단계.mjs <입장코드>
node tools\smoke-2단계.mjs            # 입장·재접속·팀 편성 (34개)
node tools\smoke-3단계.mjs            # 보드·텔레파시 한 판·점수판 3기준 (46개)

# 재시작 후 점수 유지 확인: 위 3단계를 돌린 뒤 서버를 껐다 켜고
node tools\smoke-3단계-재시작.mjs     # (11개)
node tools\smoke-4단계-봇.mjs         # 봇 11명으로 텔레파시 완주 (22개)
node tools\smoke-4단계-시트.mjs       # 시트 큐 (10개)
node tools\smoke-5단계.mjs           # 새 게임 4종 규칙 (67개, 서버 없이 실행)
node tools\smoke-6단계.mjs           # 마피아 — 역할 유출 검사 포함 (76개, 서버 없이 실행)
node tools\시트확인.mjs               # 구글시트 준비 상태 진단 (아무것도 안 바꿈)

# 화면을 눈으로 확인 (개발용)
node tools\화면찍기.mjs screen board.png          # 큰 화면
node tools\화면찍기.mjs admin admin.png 3000 1500 1500 0000   # 진행자
node tools\화면찍기.mjs "" phone.png 2500 400 860  # 휴대폰 (DOPA_TOKEN 필요)
```
